## 4. Room use cases

### 4.1 Синхронный перевод

Пример:

* channel_1 — Russian
* channel_2 — English
* channel_3 — German

User выбирает нужный язык.

### 4.2 Silent conference

channel_0 — floor/оригинал

### 4.3 Silent conference + Синхронный перевод

* channel_0 — floor language
* channel_1 — Russian
* channel_2 — English
* channel_3 — German

### 4.4 Несколько Silent залов

Несколько сцен:

* channel_1 — Stage A
* channel_2 — Stage B
* channel_3 — Stage C

В этом случае одна комната (1 VPS) может обслуживать несколько залов.
