# BYOD Audio Distribution System

## 1. Общая цель проекта

Разработать систему распределения аудиопотоков для мероприятий, позволяющую участникам прослушивать различные аудиоканалы (например, языки синхронного перевода) через собственные устройства.

Система предназначена для использования на: конференциях, форумах, синхронном переводе, silent conference, многоязычных презентациях, гибридных мероприятиях, распределении аудио дорожек на несколько залов.

Важные требования/приоритеты: 
- отказоустойчивость всей системы
- кибербезопасность
- стабильный внятный звук for users
- минимализм интерфейса for users
- мультиплатформенность for users
- упрощённость для room technician
- статистика
- контроль/управление для администратора
